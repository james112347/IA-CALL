Connesso

Guida Configurazione

Segui questi 7 passaggi per attivare il centralino AI

1
Crea gli account
Twilio, Groq, ElevenLabs, Supabase
▶

Registrati gratuitamente su questi 4 servizi:

  1. Twilio — Telefonia. Ottieni un numero di telefono virtuale
  2. Groq — AI. Genera la tua API key dal pannello
  3. ElevenLabs — Voce. 10.000 caratteri/mese gratis
  4. Supabase — Database. Crea un nuovo progetto
Tutti i servizi hanno un piano gratuito sufficiente per iniziare.
2
Configura il Database
Esegui lo schema SQL su Supabase
▶
  1. Vai su Supabase Dashboard
  2. Seleziona il tuo progetto
  3. Vai in SQL Editor nel menu a sinistra
  4. Copia e incolla il contenuto del file supabase-schema.sql
  5. Clicca Run

Questo crea le tabelle orders e call_logs con gli indici e il realtime.

Dopo aver eseguito lo SQL, vai in Settings > API e copia URL e anon key per il prossimo step.
3
Configura le variabili d'ambiente
File .env con tutte le API key
▶

Copia il file template e compilalo:

cp .env.example .env

Apri .env e inserisci le tue credenziali:

VariabileDove trovarla
TWILIO_ACCOUNT_SIDTwilio Console > Account Info
TWILIO_AUTH_TOKENTwilio Console > Account Info
TWILIO_PHONE_NUMBERIl numero Twilio (formato +39...)
GROQ_API_KEYconsole.groq.com > API Keys
ELEVENLABS_API_KEYelevenlabs.io > Profile > API Keys
ELEVENLABS_VOICE_IDelevenlabs.io > Voice Library (opzionale)
SUPABASE_URLSupabase > Settings > API > URL
SUPABASE_ANON_KEYSupabase > Settings > API > anon key
BASE_URLIl tuo URL pubblico (vedi Step 5)
4
Installa e avvia il server
npm install & npm start
▶

Apri il terminale nella cartella del progetto ed esegui:

npm install npm start

Dovresti vedere:

CENTRALINO AI ATTIVO Server: http://localhost:3000 Dashboard: http://localhost:3000
Per lo sviluppo usa npm run dev — riavvia automaticamente ad ogni modifica.
5
Esponi il server con ngrok
Twilio deve raggiungere il tuo server
▶

Twilio ha bisogno di un URL pubblico per inviare le chiamate al tuo server.

  1. Installa ngrok (gratuito)
  2. In un nuovo terminale, esegui:
ngrok http 3000

ngrok ti mostrera un URL tipo:

https://a1b2c3d4.ngrok-free.app
  1. Copia quell'URL HTTPS
  2. Aggiorna BASE_URL nel tuo file .env
  3. Riavvia il server
In produzione puoi usare un dominio fisso o deployare su Railway, Render, ecc.
6
Configura il webhook Twilio
Collega il numero di telefono al server
▶
  1. Vai su Twilio Console > Phone Numbers
  2. Clicca sul tuo numero di telefono
  3. Nella sezione Voice Configuration:
ImpostazioneValore
A call comes inWebhook
URLhttps://tuo-url.ngrok-free.app/voice/incoming
HTTP MethodPOST
  1. Clicca Save configuration
Opzionale: nel campo "Call status changes" puoi aggiungere l'URL /voice/status per tracciare la durata delle chiamate.
7
Testa il sistema!
Chiama il tuo numero e fai un ordine
▶
  1. Chiama il tuo numero Twilio dal telefono
  2. L'AI ti salutera con voce naturale (ElevenLabs)
  3. Ordina qualcosa, ad esempio: "Vorrei due pizze margherita e una birra"
  4. L'AI ripetera l'ordine e chiedera conferma
  5. Conferma con "Si, confermo"
  6. L'ordine apparira qui nella dashboard!
Se qualcosa non funziona, controlla i log nel terminale dove gira il server — gli errori vengono mostrati li.
